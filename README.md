# AI市场分析作品集

李慧的个人分析项目作品页，展示异动归因、主线归纳、行业与个股验证，以及AI辅助报告工作流。

## 网页目录

`deploy/` 是完整的静态网站目录：

- `index.html`：作品首页。
- `assets/screens/`：看板截图和视频封面。
- `assets/video/history-review.mp4`：历史复盘演示视频，约19.07MB。
- `reports/`：日报和周报样例。

部署时将 `deploy` 设置为网站发布目录，无需构建。保留目录结构和相对路径。

本仓库保存导出的网页与展示素材，不包含数据库、服务端或完整数据分析平台源码。
